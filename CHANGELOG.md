## [0.1.0] - 2025-10-27

Первый релиз пакета.

### Added

- Кнопка `📋 copy · <lang> · <NL>` под каждым закрытым блоком кода в транскрипте Pi.
- Копирование исходного текста блока: без `markdown.codeBlockIndent`, без пустых
  строк-артефактов и мягких переносов терминала, без ANSI.
- Клик мышью в fullscreen-режиме (`TuiAltScreen.handleMouseEvent`), с fallback для
  терминалов без поддержки OSC8-гиперссылок.
- Команда `/copycode [номер]` — выбор блока из последнего ответа через список.
- Хоткей `Ctrl+Alt+C` — тот же выбор с клавиатуры.
- Реестр блоков с вытеснением по лимиту `MAX_BLOCKS = 400`.
- Смоук-тесты (`npm test`): метки, клик, fallback, чужие типы сообщений, незакрытый
  блок при стриминге, `/copycode`, хоткей, откат патча прототипа при
  `session_shutdown`.
- `scripts/dev-setup.sh` — симлинки `node_modules/@earendil-works/*` на глобально
  установленный Pi (хостовые пакеты намеренно не попадают в `dependencies`).

### Known issues

- Перехват мыши опирается на патч прототипа `TuiAltScreen`: официального хука на
  мышиные события в транскрипте Pi не имеет, поэтому обновление Pi может потребовать
  правки `installMouseHook()`.
- В `tuiMode: "regular"` мышь принадлежит терминалу, доступны только хоткей и
  `/copycode`.
